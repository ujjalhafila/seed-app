Configure Supabase
Create a free project at supabase.com, then paste your credentials. Enable Google and/or GitHub OAuth providers in Authentication → Providers.

Without this, the app runs in demo mode with local storage only.
Supabase project URL
Supabase anon key
Setup steps:
1. supabase.com → New project
2. Project Settings → API → copy URL + anon key
3. Authentication → Providers → enable Google + GitHub
4. For Google: console.cloud.google.com → Credentials → OAuth 2.0 Client
5. For GitHub: github.com/settings/developers → OAuth Apps → New
